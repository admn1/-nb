# شاشة السيارة الذكية (Smart Car Touchscreen) - Landing Page

صفحة هبوط احترافية متجاوبة بالكامل باللغة العربية (RTL) لشاشة السيارة الذكية التي تعمل باللمس.

---

## 🚀 طريقة الاستخدام السريعة

1. **الفتح المباشر:**
   - يمكنك فتح ملف `index.html` مباشرة في أي متصفح بالضغط عليه مرتين.

2. **الرفع على GitHub:**
   - اسحب كل محتويات هذا الفولدر وأفلتها في مستودعك (Repository) على GitHub.
   
3. **الربط مع Vercel أو Cloudflare أو Netlify:**
   - اختر المستودع من لوحة تحكم Vercel وسيتم التعرف عليه تلقائياً كموقع ثابت (Static Website) فائق السرعة بدون أي إعدادات إضافية.
   - أضف الدومين الخاص بك `cartel.best` وسيعمل مباشرة عبر شبكة CDN العالمية.
